Where the brain lives

Arduino EEPROM, 1,024 bytes
settings and calibrationthe brainfree

Each square is one byte. The trained network's 401 numbers are squeezed to one byte each (one scale per layer), plus a header and a checksum the robot verifies before it trusts a new brain.

Open the Gym from your Mac to talk to the robot

This copy of the Gym can dream, run exams and drive a virtual robot, but browsers only let a page reach a USB device when it runs from your own computer. On your Mac, double-click Fulcrum Gym.command in the fulcrum folder (it opens this same Gym in Chrome at localhost), then come back to this tab.

1 · Connect

Plug Fulcrum into your Mac with the USB cable, then pick its port (it is usually called usbmodem or usbserial).

2 · Firmware

The program that runs on the Arduino. Install it once; after that, brains travel over the same cable without reinstalling anything.

3 · Check the parts

Sonar–wave your hand over the track
Gyro–GY-521 board on the beam
Knob–turn it end to end
Remote–press any button

4 · Calibrate

Put the ball on the track, then start. Fulcrum sweeps the servo while the gyro watches, rolls the ball both ways to learn which way is which, then finds true level. About 50 seconds.

  1. Sweep: servo position to beam angle
  2. Ball test: which way rolls away
  3. Auto-level: find true level
